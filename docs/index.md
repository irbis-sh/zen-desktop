# Documentation index

> [!NOTE]
> This documentation is aimed at Zen's developers. For documentation on how to use Zen, go to [docs.irbis.sh/docs/zen](https://docs.irbis.sh/docs/zen).

## Getting started

- [Install the dependencies](reference/requirements.md).
- Optional: Check out the [useful articles](reference/useful-articles.md).
- Familiarise yourself with [the project structure](reference/project-structure.md) and [the architecture](explanation/architecture.md).
- Run `task -l` to see available tasks.
- Run `task` to automatically install the Go/Node packages and run the app in development mode.
- Learn the [code conventions followed in the project](reference/code-conventions.md).
- Start exploring the codebase from:
  - [The Go entrypoint](/main.go).
  - [The frontend entrypoint](/frontend/src/main.tsx).
